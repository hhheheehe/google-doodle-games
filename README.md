# 🎮 Google Doodle Games Hub

A beautiful, interactive website featuring multiple Google Doodle games with smooth transitions and amazing animations. Play all your favorite games without leaving the page!

## 🎯 Features

- **Smooth Page Transitions** - Animated transitions between screens using cubic-bezier curves
- **Starfield Background** - Twinkling stars with smooth animations
- **Chrome Dinosaur Game** - The classic T-Rex game with jumping mechanics
- **PAC-MAN** - Animated Pacman game with floating ghosts
- **Snake Game** - Classic snake game with collision detection
- **Flappy Bird** - Tap to fly through obstacles
- **Responsive Design** - Works on desktop and mobile devices
- **No External Links** - All games are embedded directly in the page

## 🚀 How to Use

1. Clone the repository:
```bash
git clone https://github.com/hhheheehe/google-doodle-games.git
cd google-doodle-games
```

2. Open `index.html` in your web browser

3. Navigate through:
   - **Home** - Welcome screen with cool animations
   - **Games** - Select from 4 amazing games
   - **About** - Learn about the project

## 🎮 Games

### Chrome Dinosaur
- **Controls**: Space or Arrow Up / Click
- **Objective**: Jump over cacti and avoid obstacles
- **Score**: Earn points by dodging obstacles

### PAC-MAN
- **Objective**: Enjoy the animated Pac-Man experience
- **Features**: Colorful ghosts and smooth animations

### Snake
- **Controls**: Arrow Keys
- **Objective**: Eat food and grow longer without hitting walls or yourself
- **Score**: Get 10 points per food eaten

### Flappy Bird
- **Controls**: Space / Arrow Up / Click
- **Objective**: Fly through the pipes without hitting them
- **Score**: Get points by passing through pipes

## 💡 Game Implementation Details

### Dinosaur Game
- Canvas-based rendering
- Collision detection between dinosaur and cactus
- Progressive difficulty (increasing game speed)
- Score tracking

### Snake Game
- Grid-based movement
- Food collision detection
- Self-collision detection
- Score accumulation

### Flappy Bird
- Physics-based gravity simulation
- Pipe generation and collision detection
- Score tracking

### PAC-MAN
- CSS animations
- Floating ghost effects
- Retro gaming aesthetic
